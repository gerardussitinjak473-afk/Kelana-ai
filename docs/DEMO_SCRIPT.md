# Alur presentasi 12–15 menit

1. Masalah (1 menit): itinerary tersebar, budget tidak terlihat, riwayat pertanyaan sulit dilanjutkan.
2. Solusi dan tampilan (2 menit): buka beranda, pilih filter dan destinasi, ubah hari dan budget. Tunjukkan perubahan budget harian dan animasi pesawat.
3. Arsitektur (2 menit): Next.js memanggil FastAPI; JWT memeriksa user; service berkomunikasi dengan DB/Bedrock. Jelaskan jalur RAG terpisah dari chat.
4. Demo (5 menit): login, generate itinerary, lihat trip, tanya asisten pengetahuan, buka chat dan lanjutkan percakapan. Gunakan produksi hanya setelah VERIFICATION.md lengkap. Bila belum, jelaskan demo lokal dan batasnya sebelum mulai.
5. Tantangan dan verifikasi (2 menit): konflik merge, retry AI, konfigurasi API, persistensi history, pengurangan animasi.
6. Langkah berikutnya (1 menit): konfigurasi domain dan KB, tes publik, review keamanan, baru commit/tag rilis.

Gunakan screenshot pada PPT sebagai cadangan. Jangan mengaku screenshot lokal adalah bukti deployment produksi.
