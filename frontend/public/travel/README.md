# Travel UI/UX Asset Starter Pack

Starter resources for a modern travel/tourism website.

Contents:
- icons/ — 9 lightweight SVG travel/UI icons
- references/RESOURCE_LINKS.txt — curated Figma, travel UI, icon, and photography resources
- design-tokens.css — starter CSS design tokens

Third-party Figma/proprietary assets are referenced by URL rather than redistributed.
Review each source's current license before commercial use or redistribution.
